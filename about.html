The Thread: From Special Education to Enterprise Flows

My background started with teaching and instructional design in specialized education. In that environment, if an instruction is ambiguous or a visual layout is cluttered, the learner disengages immediately. You learn very quickly how to strip away noise, isolate core steps, and build clear mental models.

Moving into enterprise software and product design didn't change that core problem—it only changed the scale. When an ERP order-to-cash pipeline fails or a warehouse team maintains rogue Excel sheets on the side, the root cause is rarely user negligence. It is almost always a system that clashes with human working memory and daily operational reality.

My Guiding Principle: A system only works if the people using it every day can understand it under pressure. Whether configuring an order-to-cash flow or designing a mobile transit alert, the goal is always the same: removing cognitive friction so that doing the right thing is the easiest path.
